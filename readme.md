# AI & Data Consultancy Website

## Project Overview

This repository hosts the code for the **AI & Data Consultancy Website**, a modern and responsive website designed to showcase services in AI, Data Analytics, Machine Learning, and Workflow Automation. The site is built with HTML, CSS, and JavaScript, featuring a clean and intuitive design optimized for showcasing consultancy services and providing visitors with an excellent user experience.

---

## Features

### Navigation
- **Responsive Navbar**: Fully responsive navbar with a toggle menu for smaller screens.
- **Smooth Scrolling**: Navigation links smoothly scroll to the respective sections.

### Hero Section
- **Hero Banner**: A visually appealing section with a call-to-action to learn more or get in touch.

### Services
- **Service Offerings**: Detailed service descriptions categorized into:
  1. Data Analytics and Reporting
  2. Automation and Workflow Optimization
  3. Machine Learning and AI Development
  4. Computer Vision and Image Processing
- **Icons & Tools**: Each service highlights the tools and technologies used (e.g., Python, TensorFlow, Docker).

### Contact
- A **"Let's Talk"** call-to-action button to direct users to the contact section.

### Footer
- Simple footer with copyright information.

### CSS Design
- Modular CSS files for components like the navbar, services, scrollbar, and contact forms.
- FontAwesome for consistent and scalable icons.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ai-data-consultancy-website.git
   cd ai-data-consultancy-website
   ```

2. Open the `index.html` file in any modern browser:
   ```bash
   open index.html
   ```

3. For live development:
   - Use a local HTTP server like `Live Server` (VS Code extension) or Python's HTTP server:
     ```bash
     python -m http.server
     ```

4. Navigate to `http://localhost:8000` (or the displayed address) in your browser.
